# 附件层

这里放支持性附件和辅助文件。

## 适合放什么

- 截图
- 图片
- 临时图表导出
- 示意图
- Canvas
- 支持性 Excalidraw 草图
- 其他不是原始来源、但会被页面引用的文件

## 不适合放什么

- 原始来源文档
- 已整理好的摘要正文
- 应该进入 `articles/`、`concepts/` 或 `indexes/` 的内容
- 正式架构图、服务拓扑图、业务到实现总览图和跨模块数据流图；这些进入 [[projects/design/diagrams/README]]

## 维护原则

- 文件名尽量稳定，最好能看出日期、主题和用途。
- 如果某个附件只是支持某篇页面，就从那篇页面回链过来。
- 如果它本身就是原始证据，优先放 `raw/`。
