# Current Lens

`views/current/` 放当前有效的 canonical lens。

这里的文件回答“现在看这个主题，应该看哪一版视图”。如果视图只代表某个阶段、会议、验收、复盘或外部分发节点，应放入 `views/snapshots/`。

## 当前索引

当前暂无持久 current lens。

新增后必须同步 [[views/lens-registry]]。
- `current/public-html-publish-status.html`: public-html-publish live readback status sample.
