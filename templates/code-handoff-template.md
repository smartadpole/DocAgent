# 代码工程回传包模板

使用位置：[[projects/development/execution/developer-execution-workflow]]

推荐存放在实现工程内：

```text
docs/handoffs/<work-id>/README.md
```

轻量或历史兼容任务可以使用：

```text
docs/handoffs/<work-id>-<short-topic>.md
```

```md
# <work-id> | 回传包标题

- 任务 ID：
- 对应 TODO：
- 对应 FP / 候选 ID：
- 上游需求 / 目标：
- 关系类型：
- 当前 Gate / 阶段：
- 主责模块：
- 交付物类型：
- 读取输入：
- 实现范围：
- 不做项：
- 验证证据：
- 测试方案和用例执行情况：
- 相关功能回归范围：
- 参数生效证据：
- 独立抽插证据：
- 失败项：
- 未验证项：
- 关闭判断：
- 反馈回写：
- 偏差和风险：
- 提问 / 需交流事项：
- 文档建议：
- 下一步：
```

回传包不是第二份设计正文，也不是把本库页面复制进代码工程。
