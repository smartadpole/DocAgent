```md
| ID | 优先级 | 状态 | 上游需求 / 目标 | 功能点 / 候选项 | 关系类型 | 主责模块 | 输出物 | 关闭证据 | 反馈回写 | 未确认项 | 下一步 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| TODO-001 | P0 | todo |  |  | realizes |  |  |  |  |  |  |
```

## 状态口径

- `todo`：已确认要做，还未开始。
- `doing`：正在处理。
- `review`：已有输出或 handoff，等待吸收、验收或关闭证据补齐。
- `blocked`：被外部事实、owner、权限、环境或设计缺口阻塞。
- `done`：输出、测试、失败分流和回写均已完成。
- `canceled`：确认不再执行。
