# Transferable Skill Governance Transfer

## 能力目标

按真实能力与本地结构吸收外部经验，避免追分与平行真相源。 运行入口为 [[skills/transferable-skill-governance/SKILL]]；条件参考随入口按触发迁移，不全量注入每次运行。

## 可以吸收

- true-gap / recognition-gap / signal-only-gap / project-bound-gap。
- recognize / complete / upgrade / merge / adapt / defer / reject及最小耐久落点。
- 普通技能修改不自动启动矩阵；矩阵级吸收按需维护逐能力manifest。
- 系统层与intelligence evidence分开，source-depth、实际验证和external readback区分。
- 语义不变量优于字面marker，golden不按篇幅评判。

## 只能抽象吸收

外部矩阵字段、source snapshot、报告形态、owner与检查接线映射目标；历史manifest只做历史索引，不成为永久基线。

## 禁止复制

不复制来源工程身份、私有路径、项目状态、服务实例、业务数据、凭据、历史日志或一次性检查结论。源工程可访问不等于获准修改；目标已有规则和用户授权优先。迁移结果不冒充业务验收或外部评价完成。

## 目标工程结构自检

查找已有等价能力、当前owner、实际发现入口、允许写入范围和验证方法；优先复用，缺项按需要补齐。模板、reference和sensor只迁移当前能力真正消费的部分，不为形式完整预建目录。

## 验证要求

验证弱信号缺口不造空结构、等价能力复用、项目绑定能力不升通用、expected impact不写已readback；按风险使用正反例。 运行目标适用检查，说明真实变更、验证和未证明的范围；结构检查不能证明模型行为正确。
