# Research Method Route Map

仅在 [[skills/research-capability/SKILL]] 的研究问题需要以下专业方法时读取。这是方法储备，不是并列技能入口；不为覆盖面预建空技能。

## 选方法

| 问题 | 可用方法 | 必须检查的专业边界 |
| --- | --- | --- |
| 问题太大或不清 | 议题树、竞争性假设、80/20证据映射 | 拆解服务可验证问题，不等于得出结论；MECE不是机械形式要求 |
| 证据不全但要判断 | ACH、关键假设检验、敏感性与概率区间 | 反证、替代解释、假设依赖、置信度校准，不伪造精确概率 |
| 市场规模/定价 | TAM/SAM/SOM、细分、Conjoint/MaxDiff、Van Westendorp/Gabor-Granger | 明确口径、样本代表性、需求与支付行为差异；报告规模不能替代真实购买证据 |
| 用户与体验 | 招募、访谈、可用性测试、SUS/SEQ/HEART、亲和图 | 态度与行为分开、招募偏差、研究伦理、任务成功率；不能用自我想象代用户 |
| 竞争情报 | KIT/KIQ、财报/专利/招聘/Win-Loss、War Game | 区分合法公开来源、观测与推断；信号不等于对手未来动作，预警要有可证伪触发 |
| 尽职调查 | 分职能DD矩阵、三角验证、红旗分级、reference核验 | 财务/法律/商业/技术/运营/合规证据及未读清单；KYC/AML/UBO适用时检查，不替代专业批准 |
| 科研方法 | 可证伪假设、RCT/准实验/观察、PRISMA/GRADE | 因果识别、偏倚、样本量、效度、可重复性与预注册适用性；相关不等于因果 |
| 社会与政策 | 理论变革、DiD/断点/工具变量、OECD-DAC | 识别假设、反事实、异质性、外溢/意外影响、伦理和成本效益；方法名不能证明因果 |
| 战略前瞻 | STEEP/PESTEL、情景规划、Delphi、Backcasting、Three Horizons、Wild Cards | 多种可行未来、先行信号、决策韧性和选择权；不预测唯一未来 |
| 生活/现场决策 | 个人约束、当前性核验、候选比较、红旗/停止条件 | 预算/时间/地点/风险承受力，个人事实留用户授权 owner，不写成通用规则 |

只选能回答问题的方法；不强套每一种 lens 或统一技术使用策略。技术机制、开源项目、行业/AI与PoC执行见 [[skills/technology-research/SKILL]]。

## 共用证据

R0–R4深度与来源分层沿用总入口；R2+ Source Plan checkpoint、coverage matrix、Evidence Delta Re-open 和 Revision Brief/Delta Source Plan 见 [[skills/research-capability/references/deep-research]]，不另维护一套合同。

各方法都应保留溯源入口、反证面与风险门，结论强度匹配证据。需要落实行动时连接 owner、验证和刷新触发；没有本地实验只限制相关行为/采用 claim，不否认已经核验的一手事实。涉及外部联系、采购或专业批准时遵守实际授权。
