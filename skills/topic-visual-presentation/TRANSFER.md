# Topic Visual Presentation Transfer

## 能力目标

建立唯一主题呈现入口及其不可上推边界。

## 可以吸收

`admit / reject / clarify / abstain`、即时 `subject_package + source_pack`、typed relation 与 lifecycle、organization/adaptation、三轴运行、HTML 默认与同源 PDF/PNG、五门 evaluator、版本化 semantic judge trace、独立 public publish 和 grandfather baseline。

## 只能抽象吸收

目标工程必须本地裁决 owner、export workspace、calibration、rubric、trace 与 live/deny readback。

## 禁止复制

不得复制业务事实、旧 skill/template/checker 作为 alias、历史 HTML 文本或 PDF/PNG truth source。

## 目标工程结构自检

检查 owner、ignored export workspace、registry、public profile、sensor、fixture 和 baseline。

## 验证要求

跑 schema/mutation scanner、真实 HTML/PDF/PNG readback 与适用的 live/deny readback；最终说明 evidence boundary。
