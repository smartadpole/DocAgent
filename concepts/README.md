# 概念层

这里放概念页、工具页、方法页。

## 适合放什么

- 工具名，比如 `Claude Code`、`Codex CLI`、`Obsidian`
- 方法名，比如 `LLM 编译`、`双向链接`、`PRD 写作`
- 项目名、栏目名、固定术语

## 每页建议包含

- 定义
- 相关页面
- 常见用法
- 适用场景
- 未解决的问题

## 维护原则

- 同一个概念只保留一个主页面。
- 看到新文章提到这个概念，就回连到它。
- 如果某个概念开始频繁出现，再补一页，不要提前铺太多空页。
