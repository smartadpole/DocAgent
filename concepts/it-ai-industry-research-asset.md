# IT / AI 行业研究资产

IT / AI 行业研究资产，是面向一个行业方向、AI 赛道、产品领域、公司群体或落地场景形成的决策型知识包。

它不只解释“这个方向是什么”，而是判断它在产业中处于什么阶段、技术是否成熟、谁在做、怎么赚钱、我们能不能切入、该投入多少资源。

相关：[[articles/2026-06-09-it-ai-industry-research-methodology]]、[[skills/industry-ai-research/SKILL]]、[[templates/industry-ai-research-template]]、[[concepts/technical-research-knowledge-asset]]、[[concepts/open-source-project-due-diligence]]

## 定义

一个 IT / AI 行业研究资产至少要覆盖六层：

| 层级 | 回答的问题 |
| --- | --- |
| 宏观趋势 | 是长期趋势、短期热点，还是泡沫消退中的方向 |
| 技术路线 | 技术栈、路线、瓶颈和工程成熟度是什么 |
| 产品应用 | 用户是谁，为什么付费，是否进入真实工作流 |
| 公司竞争 | 谁领先，壁垒来自模型、数据、渠道、产品还是 Know-how |
| 开源生态 | 能否借助开源降低试错、部署和私有化成本 |
| 落地治理 | 安全、合规、评测、审计、人工介入和上线边界是什么 |

## IT 和 AI 的侧重点

IT 行业调研偏向企业软件、基础设施、预算迁移、系统替换、组织采购、集成和运维治理。

AI 领域调研在此基础上，还必须增加：

- 模型能力和成本曲线。
- 数据、算力、评测和推理基础设施。
- Agent / RAG / tool calling 等应用架构。
- 开源模型和开源框架成熟度。
- 幻觉、Prompt Injection、工具越权、版权和隐私风险。
- 从试点到生产的 ROI、组织流程和治理能力。

## 典型输出

- 行业地图。
- 技术路线图。
- 公司和竞争格局。
- 产品形态和案例。
- 开源生态清单。
- 风险与治理清单。
- 机会判断卡。
- PoC 路线。
- 推荐等级和观察指标。

## 常见误区

- 把 AI 行业调研做成热点列表。
- 只看模型能力，不看产品、ROI、组织流程和治理。
- 只看融资和新闻，不看壁垒和商业闭环。
- 只列开源项目，不判断成熟度、license 和可用性。
- 把媒体和自媒体观点当结论，而不是线索。
- 没有写清“我们应该学习、试点、产品化、创业，还是观察”。
