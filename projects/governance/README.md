# 跨工程治理产出目录

本目录承接治理中控的运行产物。规则和标准在 [[governance/platform-standards]]，审计技能在 [[skills/cross-project-governance-audit/SKILL]]。

## 文件清单

- [[projects/governance/registry]]：工程注册表。记录哪些工程在治理范围、路径、成熟度和治理阶段。每次审计后更新。
- `drift-report-YYYY-MM.md`：月度漂移报告。每次全量审计输出一份，同月覆盖更新。
- `handoff-{project}-YYYY-MM.md`：单工程 handoff 包。按需生成，用户手动带去目标工程执行。

## 使用方式

- **查看各工程治理状态**：看 [[projects/governance/registry]]
- **触发一次审计**：对话中说"审计 [工程名]"或"审计所有工程"
- **定期审计**：每周一 9:00 自动运行，结果通知到本 session
- **执行治理**：拿 handoff 包，在目标工程对话里说"按这个 handoff 执行"
